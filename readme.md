# Projet "Faux Gmail"

Le projet "Faux Gmail" est une interface de messagerie web minimaliste, construite avec les fondations du web : HTML pour sa structure et CSS pour son apparence.

Son principe fondamental est de **démontrer la facilité avec laquelle une fausse page internet, imitant des interfaces familières, peut être créée à des fins potentiellement malveillantes.**

Bien que visuellement inspirée des plateformes de messagerie courantes, "Faux Gmail" n'est pas une véritable application de messagerie.

Son objectif premier est de souligner la simplicité technique requise pour concevoir une page web trompeuse, capable de leurrer des utilisateurs peu méfiants.
<br>
En se concentrant sur une apparence familière et des interactions de base, cette interface met en évidence comment des acteurs malintentionnés pourraient exploiter la confiance des utilisateurs envers des designs connus pour collecter des informations sensibles ou mener d'autres actions malveillantes.

"Faux Gmail", réalisé uniquement en HTML et CSS, illustre de manière concrète que la sophistication visuelle d'une page web ne garantit pas son authenticité ou sa sécurité.

Ce projet se veut une piqûre de rappel sur la nécessité de la vigilance et de la sensibilisation aux risques de phishing et d'ingénierie sociale sur internet.

Il prouve qu'avec des compétences techniques de base, il est aisé de créer une contrefaçon d'interface web suffisamment convaincante pour tromper.
